# **App Name**: AgriAssist

## Core Features:

- Multilingual Support: Provide crop advisory in multiple languages.
- AI-Powered Crop Advisory: Provide real-time, location-specific crop recommendations. LLM acts as a tool to retrieve most recent information and trends, in order to decide whether and how to incorporate it into the AI's output
- Voice Support: Enable voice-based interaction for low-literate users.
- Weather Alerts: Send weather-based alerts to farmers.
- Market Price Tracking: Track market prices for crops in different locations.
- Pest/Disease Detection: Allow users to upload images for pest/disease detection and give associated crop advice. LLM acts as a tool to decide whether the automatically predicted advice should be given directly to the user, or displayed as one possibility among others.
- Feedback Collection: Collect user feedback for continuous improvement.

## Style Guidelines:

- Primary color: Earthy Green (#6B8E23) to represent agriculture and growth.
- Background color: Light Beige (#F5F5DC) to provide a neutral and clean background.
- Accent color: Golden Yellow (#FFD700) to highlight important information and CTAs.
- Body and headline font: 'PT Sans' (humanist sans-serif) for a modern yet approachable feel.
- Use clear, representational icons for different crop types and alerts.
- Prioritize a simple, intuitive layout for easy navigation, especially for low-literate users.
- Use subtle transitions and animations to enhance user experience.
